# AoeNameCountdown

welcome to the most serious scientific timer lab on earth.

this project answers one question:
"how many seconds does aaooee have left to say the name?"

current approach:
- start with 30000 seconds
- display number very loudly
- let time do crime

## what this thing is
- one single `index.html`
- all css in there
- all js in there
- no build step
- no backend
- no peace

## features
- pixel retro style that looks like an arcade machine ate a calculator
- countdown logic tied to a fixed daily start time
- localStorage memory so reload does not erase the drama
- button with multiple confirmation dialogs for maximum emotional damage

## run it
1. clone repo
2. open `index.html` in browser
3. stare at the countdown like it owes you money

or if you want local server wizardry:

```bash
python -m http.server 8000
```

then open `http://localhost:8000`
